Keep the relationships in view

Concentration

M = n / Vsolution, L

m = n / masssolvent, kg

Molarity uses solution volume. Molality uses solvent mass.

Freezing point

ΔTf = iKfm

Tf = Tf° − ΔTf

ΔTf is a positive decrease. Use the given ideal van’t Hoff factor.

Solubility

AaBb(s) ⇌ aA + bB

Ksp ≈ ([A]/c°)a([B]/c°)b

At saturation; c° = 1 mol/L. Omit the pure solid.

Titration

n = MV, with V in L

nanalyte/νanalyte = ntitrant/νtitrant

ν is a coefficient in the balanced reaction. Use the mole ratio at equivalence.
